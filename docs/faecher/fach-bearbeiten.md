# Fach bearbeiten

## Fach umbenennen

1. Klicken Sie auf den **Bearbeiten-Button** neben dem Fach-Tab
2. Ändern Sie den Namen
3. Bestätigen Sie mit **Speichern**

## Anwesenheitseinstellungen ändern

Im selben Bearbeitungsdialog können Sie auch die Anwesenheitseinstellungen des Fachs anpassen:

- **Mindestanwesenheit** — Minimum in Prozent
- **Warnschwelle** — Wann eine Warnung angezeigt wird
- **Automatische Benotung** — An/Aus-Schalter

![Fach bearbeiten](/img/edit-subject.png)

:::info Hinweis
Wenn das Fach als [Standardfach](standardfaecher.md) konfiguriert ist, werden Änderungen an den Anwesenheitseinstellungen auf alle gleichnamigen Fächer in allen Klassen und Jahren übertragen.
:::
