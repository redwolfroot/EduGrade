# Fach hinzufügen

Fächer werden pro Schuljahr verwaltet. Jedes Fach hat eine eigene Notentabelle und eigene Anwesenheitseinstellungen.

## Neues Fach anlegen

1. Klicken Sie auf das **+**-Symbol in der Fächerleiste (oberhalb der Notentabelle)
2. Geben Sie den **Fachnamen** ein (max. 50 Zeichen)
3. Optional: Konfigurieren Sie die **Anwesenheitseinstellungen**:
   - **Mindestanwesenheit** in Prozent (z.B. 75%)
   - **Warnschwelle** in Prozent (z.B. 5% über Minimum)
   - **Automatische Benotung** — Schüler unter Mindestanwesenheit erhalten automatisch Note 5
4. Bestätigen Sie mit **Erstellen**

![Fach hinzufügen](/img/add-subject.png)

## Anwesenheitseinstellungen

Jedes Fach kann individuelle Anwesenheitsregeln haben:

| Einstellung | Beschreibung | Beispiel |
|-------------|-------------|----------|
| Mindestanwesenheit | Minimale Anwesenheit in % | 75% |
| Warnschwelle | Warnung ab diesem Abstand zum Minimum | 5% |
| Auto-Benotung | Automatisch Note 5 bei Unterschreitung | An/Aus |

Wenn ein Fach denselben Namen wie ein [Standardfach](standardfaecher.md) hat, werden die Anwesenheitseinstellungen automatisch übernommen.
