# Standardfächer

Standardfächer werden automatisch für jede neue Klasse erstellt. So müssen Sie nicht jedes Mal dieselben Fächer manuell anlegen.

## Standardfächer konfigurieren

1. Öffnen Sie **Einstellungen** → **Profil**
2. Scrollen Sie zum Bereich **Standardfächer**
3. Geben Sie einen Fachnamen ein und klicken Sie auf **Hinzufügen**
4. Wiederholen Sie dies für alle gewünschten Fächer

![Standardfächer konfigurieren](/img/default-subjects.png)

## Anwesenheitseinstellungen für Standardfächer

Sie können für jedes Standardfach eigene Anwesenheitsregeln festlegen. Diese werden automatisch auf alle Fächer mit demselben Namen angewandt.

## Synchronisation

Standardfächer wirken als **Vorlagen**:

- Änderungen an einer Vorlage werden auf **alle gleichnamigen Fächer** in allen Klassen und Jahren übertragen
- Dies gilt nur für die Anwesenheitseinstellungen, nicht für Noten

:::tip Tipp
Legen Sie Ihre Standardfächer am besten gleich nach der Registrierung fest, bevor Sie Ihre erste Klasse erstellen.
:::
