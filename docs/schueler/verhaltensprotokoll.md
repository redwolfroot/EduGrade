# Verhaltensprotokoll

Mit dem Verhaltensprotokoll halten Sie Beobachtungen zum Verhalten eines Schülers fest — jeweils mit **Fach, Datum und Uhrzeit**. So haben Sie z. B. für Elterngespräche oder Konferenzen eine nachvollziehbare Dokumentation.

## Eintrag anlegen

Sie können an mehreren Stellen einen Eintrag anlegen:

- in der Klassenansicht über den **Protokoll-Button** in der Zeile des Schülers
- in der Schnellansicht (Klick auf eine Schülerzeile) über **Verhalten**
- in der [Detailansicht](../schueleransicht/detailansicht.md) im Abschnitt **Verhaltensprotokoll** über **Verhalten protokollieren**
- mobil über den **+**-Button in der Klassenansicht → **Verhalten protokollieren**

Im Dialog geben Sie an:

- **Fach** — vorausgewählt ist das aktive Fach
- **Datum** und **Uhrzeit** — vorausgefüllt mit dem aktuellen Zeitpunkt, bei Bedarf änderbar
- **Art** — Positiv, Neutral oder Negativ
- **Beschreibung** — Pflichtfeld (max. 500 Zeichen)

## Einträge ansehen, bearbeiten und löschen

Die Detailansicht zeigt alle Einträge des aktiven Fachs, die neuesten zuerst, und darüber die Anzahl positiver, neutraler und negativer Einträge. Über die Buttons in der Zeile können Sie einen Eintrag **bearbeiten** oder **löschen**.

In der EduGrade-App für Android finden Sie das Verhaltensprotokoll in der Detailansicht des Schülers.

## Wer sieht die Einträge?

Das Verhaltensprotokoll ist nur für Sie sichtbar. Es wird **nicht** über den [Zugangslink für Schüler](../teilen/zugangslink-erstellen.md) geteilt. Bei einer Klassenübergabe innerhalb einer Organisation können Sie selbst entscheiden, ob das Protokoll mit übergeben wird.

:::note Hinweis
Wenn Sie ein Fach löschen, werden auch alle Verhaltenseinträge dieses Fachs gelöscht. Beim Anlegen eines neuen Schuljahres werden keine Einträge übernommen.
:::
