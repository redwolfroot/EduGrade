# Schüler hinzufügen

Schüler werden pro Schuljahr verwaltet. Wenn Sie das Schuljahr wechseln, sehen Sie andere Schüler.

## Einzelnen Schüler hinzufügen

1. Öffnen Sie die gewünschte Klasse und das richtige Schuljahr
2. Klicken Sie auf **Schüler hinzufügen**
3. Füllen Sie das Formular aus:
   - **Vorname** — Pflichtfeld (max. 50 Zeichen)
   - **Nachname** — Pflichtfeld (max. 50 Zeichen)
   - **Zweiter Vorname** — Optional (max. 50 Zeichen)
4. Bestätigen Sie mit **Hinzufügen**

![Schüler hinzufügen](/img/add-student.png)

## Duplikaterkennung

EduGrade prüft automatisch, ob bereits ein Schüler mit demselben Namen im aktuellen Schuljahr existiert. Ist dies der Fall, werden Sie darauf hingewiesen.

:::tip Tipp
Für viele Schüler auf einmal nutzen Sie den [CSV-Import](schueler-importieren.md) — das spart viel Zeit!
:::
