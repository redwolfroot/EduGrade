# Schüler löschen

## Einzelnen Schüler löschen

1. Klicken Sie auf den **Löschen-Button** neben dem Schülernamen
2. Bestätigen Sie die Sicherheitsabfrage

## Mehrere Schüler gleichzeitig löschen

1. Wählen Sie mehrere Schüler über die **Checkboxen** in der Klassenansicht aus
2. Klicken Sie auf **Ausgewählte löschen**
3. Bestätigen Sie die Sicherheitsabfrage (die Anzahl wird angezeigt)

:::danger Achtung
Beim Löschen eines Schülers werden **alle seine Noten** und **Anwesenheitsdaten** unwiderruflich entfernt. Dieser Vorgang kann nicht rückgängig gemacht werden.
:::
