# Anmeldung

## Login

1. Öffnen Sie die EduGrade-Webseite
2. Geben Sie Ihre **E-Mail-Adresse** und Ihr **Passwort** ein
3. Klicken Sie auf **Anmelden**

![Login-Formular](/img/login-form.png)

## Passwort vergessen?

Falls Sie Ihr Passwort vergessen haben, benötigen Sie Ihren **Wiederherstellungsschlüssel**:

1. Klicken Sie auf **Passwort vergessen?** auf der Login-Seite
2. Geben Sie Ihre E-Mail-Adresse ein
3. Geben Sie Ihren Wiederherstellungsschlüssel ein
4. Legen Sie ein neues Passwort fest

:::warning Achtung
Ohne Wiederherstellungsschlüssel kann Ihr Passwort **nicht** zurückgesetzt werden, da Ihre Daten verschlüsselt sind. In diesem Fall müssen alle Daten gelöscht werden. Bewahren Sie Ihren Schlüssel daher gut auf!
:::

Mehr zum Wiederherstellungsschlüssel finden Sie unter [Wiederherstellungsschlüssel](wiederherstellungsschluessel.md).
