# Wiederherstellungsschlüssel

Der Wiederherstellungsschlüssel ist Ihr Sicherheitsnetz für den Fall, dass Sie Ihr Passwort vergessen.

## Warum ist der Schlüssel so wichtig?

Ihre Daten werden in EduGrade **verschlüsselt** gespeichert. Das Passwort dient als Schlüssel für diese Verschlüsselung. Der Wiederherstellungsschlüssel ist die **einzige Alternative**, um bei einem Passwortverlust wieder Zugang zu Ihren verschlüsselten Daten zu erhalten.

:::danger Ohne Schlüssel kein Zugang
Wenn Sie sowohl Ihr Passwort als auch Ihren Wiederherstellungsschlüssel verlieren, sind Ihre Daten **unwiederbringlich verloren**. Es gibt keine andere Möglichkeit der Wiederherstellung.
:::

## Neuen Schlüssel generieren

Falls Sie Ihren Schlüssel verlegt haben, aber noch angemeldet sind:

1. Öffnen Sie die **Einstellungen**
2. Gehen Sie zum Bereich **Profil**
3. Klicken Sie auf **Neuen Wiederherstellungsschlüssel generieren**
4. Speichern Sie den neuen Schlüssel sofort ab

![Wiederherstellungsschlüssel generieren](/img/regenerate-recovery-key.png)

:::info Hinweis
Der alte Schlüssel wird dadurch ungültig. Nur der neue Schlüssel funktioniert für die Passwortwiederherstellung.
:::

## Schlüssel per E-Mail senden

Sie können den Wiederherstellungsschlüssel als PDF an Ihre E-Mail-Adresse senden lassen. Diese Option steht sowohl bei der Registrierung als auch in den Einstellungen zur Verfügung.

## Empfohlene Aufbewahrung

- Drucken Sie den Schlüssel aus und bewahren Sie ihn an einem sicheren Ort auf
- Speichern Sie ihn in einem Passwort-Manager
- Machen Sie ein Foto und speichern Sie es sicher ab
