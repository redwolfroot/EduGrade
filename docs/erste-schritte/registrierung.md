# Registrierung

Um EduGrade nutzen zu können, benötigen Sie einen persönlichen Account.

## Account erstellen

1. Öffnen Sie die EduGrade-Webseite
2. Klicken Sie auf **Registrieren**
3. Füllen Sie das Formular aus:
   - **Benutzername** — Ihr gewünschter Anzeigename
   - **E-Mail-Adresse** — Wird für die Anmeldung verwendet
   - **Passwort** — Mindestens 8 Zeichen
4. Klicken Sie auf **Account erstellen**

![Registrierungsformular](/img/registration-form.png)

## Wiederherstellungsschlüssel

Nach der Registrierung wird Ihnen ein **Wiederherstellungsschlüssel** angezeigt.

:::danger Wichtig
Dieser Schlüssel wird **nur einmal** angezeigt! Speichern Sie ihn an einem sicheren Ort (z.B. ausdrucken oder in einem Passwort-Manager ablegen). Ohne diesen Schlüssel können Sie bei einem vergessenen Passwort **nicht** auf Ihre Daten zugreifen.
:::

### Wiederherstellungsschlüssel per E-Mail senden

Sie können sich den Schlüssel auch als **PDF per E-Mail** zusenden lassen. Klicken Sie dazu auf die entsprechende Schaltfläche im Dialog nach der Registrierung.

![Wiederherstellungsschlüssel Dialog](/img/recovery-key-dialog.png)

## Nächste Schritte

Nach der Registrierung werden Sie automatisch angemeldet. Fahren Sie fort mit dem [Einrichten Ihres Profils](profil-einrichten.md).
