# Handy-Kopplung

Mit der Handy-Kopplung wird die EduGrade-App auf Ihrem Android-Handy zum **Schlüssel Ihres Kontos**:

- **Ohne Passwort:** Im Browser melden Sie sich nur mit Ihrer **E-Mail-Adresse** und einem **6-stelligen Code** an, den Ihr gekoppeltes Handy anzeigt – ähnlich wie bei einem Passkey.
- **Sicherer:** Ohne Ihr Handy kommt niemand in Ihr Konto. Ein gestohlenes Passwort allein reicht nicht mehr.
- **Einfacher:** Die gekoppelte App bleibt **dauerhaft angemeldet** – auch nach Updates des Servers.

Die Kopplung ist freiwillig. Pro Konto kann ein Handy gekoppelt sein.

## Handy koppeln

Beim ersten Anmelden in der App fragt EduGrade, ob Sie das Handy koppeln möchten. Tippen Sie auf **Ja, koppeln**.

Haben Sie zuerst abgelehnt, geht es später unter **Einstellungen → Handy-Kopplung → Dieses Handy koppeln**.

Nach dem Koppeln bietet die App eine **App-Sperre** an (Fingerabdruck, Gesicht oder Displaysperre des Handys). Sie ist freiwillig, aber empfohlen, weil das Handy nun der Schlüssel zu Ihrem Konto ist. Sie lässt sich jederzeit in den Einstellungen ein- und ausschalten.

## Im Browser anmelden

1. Geben Sie Ihre **E-Mail-Adresse** ein und klicken Sie auf **Weiter** – ein Passwort wird nicht abgefragt
2. Öffnen Sie EduGrade auf Ihrem gekoppelten Handy – dort erscheint die Anmeldung mit einem **6-stelligen Code**
3. Tippen Sie den Code im Browser ab

Der Code erscheint nur, solange die App geöffnet ist. Er ist **3 Minuten** gültig und kann nur einmal verwendet werden. Nach 5 falschen Versuchen müssen Sie neu beginnen. Nach 10 falschen Codes an einem Tag fragt EduGrade für 24 Stunden zusätzlich wieder nach dem Passwort.

:::warning Das waren Sie nicht?
Erscheint auf dem Handy eine Anmeldung, die Sie nicht selbst gestartet haben, tippen Sie auf **Das war ich nicht**. Die Anmeldung wird blockiert. Da jemand Ihr Passwort kennt, sollten Sie es bald ändern.
:::

## Kopplung aufheben

In der App unter **Einstellungen → Handy-Kopplung → Kopplung aufheben** (mit Ihrem Passwort bestätigen). Die App bleibt dabei angemeldet; im Browser melden Sie sich danach wieder mit dem Passwort an.

:::tip Passwort trotzdem merken
Auch mit gekoppeltem Handy brauchen Sie Ihr Passwort noch – zum Aufheben der Kopplung und für den Notfall-Weg unten. Falls Sie es vergessen haben, setzen Sie es mit dem Wiederherstellungsschlüssel zurück.
:::

Eine gekoppelte App lässt sich nicht einfach abmelden – heben Sie zuerst die Kopplung auf.

## Handy nicht zur Hand, verloren oder App neu installiert?

Dann kann Ihr Handy keinen Code anzeigen. So kommen Sie trotzdem in Ihr Konto:

1. Geben Sie im Browser Ihre E-Mail-Adresse ein
2. Klicken Sie im Code-Schritt auf **Handy nicht zur Hand, verloren oder App neu installiert?**
3. Geben Sie Ihr **Passwort** und Ihren [Wiederherstellungsschlüssel](wiederherstellungsschluessel.md) ein

Die alte Kopplung wird aufgehoben und das verlorene Handy abgemeldet. Danach können Sie ein neues Handy koppeln.

:::info Hinweis
Wenn Sie Ihr Passwort über den Wiederherstellungsschlüssel zurücksetzen, wird die Kopplung ebenfalls aufgehoben. Koppeln Sie das Handy danach einfach neu.
:::
