# Interaktives Tutorial

Beim ersten Login führt Sie ein interaktives Tutorial Schritt für Schritt durch die wichtigsten Funktionen von EduGrade.

![Tutorial-Fenster](/img/tutorial-welcome.png)

## Was zeigt das Tutorial?

Das Tutorial führt Sie durch folgende Schritte:

1. **Willkommen** — Kurze Einführung in EduGrade
2. **Noteneinstellungen öffnen** — Wo Sie Kategorien und Gewichtungen konfigurieren
3. **Erste Kategorie anlegen** — z.B. "Schularbeit" mit Gewichtung
4. **Notenbereiche verstehen** — Wie Prozent in Noten umgerechnet werden
5. **Ersten Schüler hinzufügen** — Einen Schüler in Ihre Klasse eintragen
6. **Erste Note vergeben** — Eine Note für den Schüler eintragen
7. **Ergebnisse in der Tabelle sehen** — Die Notenübersicht verstehen
8. **Schüler-Detailansicht öffnen** — Detaillierte Statistiken eines Schülers
9. **Note bearbeiten** — Wie Sie Noten nachträglich ändern
10. **Schuljahre & Fächer** — Wie Sie zwischen Jahren und Fächern wechseln
11. **Abschluss** — Zusammenfassung und Tipps

## Tutorial bedienen

- Klicken Sie auf **Weiter**, um zum nächsten Schritt zu gelangen
- Einige Schritte warten darauf, dass Sie eine Aktion ausführen (z.B. eine Kategorie anlegen)
- Sie können das Tutorial jederzeit mit **Überspringen** beenden

## Tutorial erneut starten

Möchten Sie das Tutorial nochmals durchlaufen? Die Option finden Sie in den **Einstellungen**.

:::tip Tipp
Das Tutorial ist der schnellste Weg, um alle wichtigen Funktionen kennenzulernen. Nehmen Sie sich 5 Minuten Zeit dafür!
:::
