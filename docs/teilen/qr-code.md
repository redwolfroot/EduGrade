# QR-Code

Für einen schnellen Zugang können Sie einen **QR-Code** generieren, den Schüler mit ihrem Smartphone scannen.

## QR-Code anzeigen

1. Erstellen Sie einen [Zugangslink](zugangslink-erstellen.md)
2. Klicken Sie auf **QR-Code anzeigen**
3. Der QR-Code enthält die URL zum Notenzugang

![QR-Code](/img/qr-code.png)

## Verwendung

- **Im Klassenzimmer** — Zeigen Sie den QR-Code am Beamer, damit alle Schüler ihn scannen können
- **Ausdrucken** — Drucken Sie den QR-Code auf ein Arbeitsblatt
- **Digital teilen** — Senden Sie den QR-Code über eine Lernplattform

Die Schüler benötigen nach dem Scannen noch ihren individuellen [PIN](pins-verwalten.md), um ihre Noten einzusehen.
