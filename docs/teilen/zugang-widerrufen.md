# Zugang widerrufen

Sie können einen geteilten Notenzugang jederzeit widerrufen.

## Zugang sofort sperren

1. Öffnen Sie den Bereich **Noten teilen**
2. Klicken Sie auf **Zugang widerrufen**
3. Bestätigen Sie die Sicherheitsabfrage

## Auswirkungen

Nach dem Widerruf:

- Der Zugangslink ist **sofort ungültig**
- Alle PINs werden **deaktiviert**
- Schüler können **keine Noten mehr einsehen**
- Um den Zugang wieder zu aktivieren, muss ein **neuer Zugangslink** erstellt werden

:::tip Tipp
Widerrufen Sie den Zugang, wenn Sie Noten aktualisieren möchten, ohne dass Schüler Zwischenstände sehen. Erstellen Sie danach einfach einen neuen Zugangslink.
:::
