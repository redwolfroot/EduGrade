# PINs verwalten

Jeder Schüler erhält einen individuellen 6-stelligen PIN, um auf seine Noten zuzugreifen.

## Wie funktionieren PINs?

1. Beim Erstellen eines [Zugangslinks](zugangslink-erstellen.md) wird für jeden Schüler automatisch ein **6-stelliger PIN** generiert
2. Die PINs werden **einmalig** nach der Erstellung angezeigt
3. Schüler geben den PIN ein, um ihre Noten einzusehen

![PIN-Liste](/img/pin-list.png)

## PINs an Schüler verteilen

- Notieren oder drucken Sie die PINs nach der Erstellung
- Verteilen Sie jedem Schüler **nur seinen eigenen** PIN
- Teilen Sie den Zugangslink (URL oder [QR-Code](qr-code.md)) mit der Klasse

## PINs neu generieren

Falls PINs verloren gehen oder Sie die Sicherheit erhöhen möchten:

1. Öffnen Sie den Bereich **Noten teilen**
2. Klicken Sie auf **PINs neu generieren**
3. Bestätigen Sie die Sicherheitsabfrage

:::warning Achtung
Beim Neugenerieren werden alle alten PINs ungültig. Sie müssen die neuen PINs erneut an die Schüler verteilen.
:::

## Schülerzugang

Aus Schülersicht sieht der Zugang so aus:

1. Schüler öffnen den Zugangslink (oder scannen den QR-Code)
2. Sie geben ihren **6-stelligen PIN** ein
3. Sie sehen nur die vom Lehrer freigegebenen Informationen
4. Kein Bearbeiten oder Exportieren möglich
