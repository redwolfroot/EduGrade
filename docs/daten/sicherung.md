# Datensicherung

EduGrade sichert Ihre Daten auf mehreren Ebenen.

## Automatische Speicherung

- Jede Änderung wird automatisch nach **0,5 Sekunden** auf dem Server gespeichert
- Beim Schließen des Browsers werden ausstehende Änderungen gespeichert
- Ein **lokaler Cache** speichert Ihre Daten zusätzlich im Browser

## Offline-Modus

Wenn Ihre Internetverbindung unterbrochen wird:

1. EduGrade zeigt einen **Offline-Indikator** an
2. Ihre Änderungen werden **lokal gespeichert**
3. Sobald die Verbindung wiederhergestellt ist, werden die Daten automatisch **synchronisiert**
4. Sie erhalten eine Benachrichtigung: "Ausstehende Änderungen synchronisiert"

## Empfehlungen für die Datensicherung

| Aktion | Empfohlener Rhythmus |
|--------|---------------------|
| JSON-[Export](export.md) | Wöchentlich |
| [Wiederherstellungsschlüssel](../erste-schritte/wiederherstellungsschluessel.md) prüfen | Einmal pro Semester |
| Exportdatei an sicherem Ort ablegen | Nach jedem Export |

:::tip Best Practice
Speichern Sie Ihre Backup-Dateien an einem sicheren Ort — z.B. auf einem USB-Stick, in einer Cloud (Google Drive, Nextcloud) oder auf dem Schulserver.
:::
