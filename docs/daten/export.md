# Daten exportieren

Sichern Sie alle Ihre Daten als JSON-Datei — als Backup oder zur Übertragung auf ein anderes Gerät.

## Export durchführen

1. Öffnen Sie **Einstellungen** → **Daten**
2. Klicken Sie auf **Daten exportieren**
3. Die Datei wird automatisch heruntergeladen

Der Dateiname enthält das aktuelle Datum: `edugrade_2026-03-20.json`

![Daten exportieren](/img/export-data.png)

## Was wird exportiert?

Die Exportdatei enthält **alle Ihre Daten**:

- Alle Klassen mit Schuljahren
- Alle Fächer
- Alle Schüler
- Alle Noten
- Alle Anwesenheitsdaten
- Kategorien und Einstellungen

:::tip Empfehlung
Erstellen Sie regelmäßig Backups, z.B. am Ende jeder Woche. So verlieren Sie im schlimmsten Fall nur wenige Tage an Daten.
:::
