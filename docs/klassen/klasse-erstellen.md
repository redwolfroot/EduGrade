# Klasse erstellen

Klassen sind die oberste Organisationsebene in EduGrade. Jede Klasse enthält Schuljahre, Fächer und Schüler.

## Neue Klasse anlegen

1. Klicken Sie auf das **+**-Symbol in der Seitenleiste
2. Geben Sie den **Klassennamen** ein (z.B. "3A", "2B Deutsch")
3. Bestätigen Sie mit **Erstellen**

![Klasse erstellen](/img/create-class.png)

## Was passiert automatisch?

Beim Erstellen einer neuen Klasse wird automatisch:

- Ein **Schuljahr** angelegt (z.B. "2025/2026" basierend auf dem aktuellen Datum)
- Alle **Standardfächer** aus Ihrem Profil hinzugefügt (sofern konfiguriert)

Die neue Klasse wird sofort in der Seitenleiste angezeigt und automatisch ausgewählt.

## Klassennamen

- Maximal **50 Zeichen**
- Wählen Sie einen eindeutigen, wiedererkennbaren Namen
- Beispiele: "1A", "3B Mathe", "Klasse 4C"

:::tip Tipp
Konfigurieren Sie zuerst Ihre [Standardfächer](../einstellungen/profil.md), damit neue Klassen automatisch mit den richtigen Fächern angelegt werden.
:::
