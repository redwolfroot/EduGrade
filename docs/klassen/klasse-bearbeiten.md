# Klasse bearbeiten

## Klasse umbenennen

1. Klicken Sie in der Seitenleiste auf den **Bearbeiten-Button** neben dem Klassennamen
2. Oder öffnen Sie das **Kontextmenü** der Klasse
3. Ändern Sie den Namen im Dialog
4. Bestätigen Sie mit **Speichern**

![Klasse bearbeiten](/img/edit-class.png)

Im Bearbeitungsdialog sehen Sie außerdem eine Übersicht über die Klasse:

- Anzahl der **Schüler**
- Anzahl der **Noten**

So wissen Sie auf einen Blick, wie viele Daten mit dieser Klasse verknüpft sind.
