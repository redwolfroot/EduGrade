# Klasse löschen

## Vorgehen

1. Öffnen Sie das **Kontextmenü** der Klasse in der Seitenleiste
2. Wählen Sie **Löschen**
3. Bestätigen Sie die Sicherheitsabfrage

![Klasse löschen](/img/delete-class.png)

## Was wird gelöscht?

Beim Löschen einer Klasse werden **alle zugehörigen Daten** unwiderruflich entfernt:

- Alle **Schuljahre** der Klasse
- Alle **Fächer** aller Schuljahre
- Alle **Schüler** aller Schuljahre
- Alle **Noten** aller Schüler
- Alle **Anwesenheitsdaten**

:::danger Achtung
Das Löschen einer Klasse kann **nicht rückgängig** gemacht werden. Erstellen Sie vorher ein [Backup](../daten/export.md), wenn Sie die Daten eventuell noch benötigen.
:::
