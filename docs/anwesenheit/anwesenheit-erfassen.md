# Anwesenheit erfassen

EduGrade ermöglicht es Ihnen, die Anwesenheit Ihrer Schüler pro Fach und Datum zu dokumentieren.

## Einzelne Anwesenheit eintragen

1. Wechseln Sie in die **Anwesenheitsansicht** der Klasse
2. Wählen Sie das **Fach** und das **Datum**
3. Setzen Sie den Status für jeden Schüler:

| Status | Symbol | Bedeutung |
|--------|--------|-----------|
| Anwesend | ✓ | Schüler war anwesend |
| Verspätet | ⏰ | Schüler kam zu spät |
| Abwesend | ✗ | Schüler war nicht anwesend |

4. Optional: Fügen Sie eine **Notiz** hinzu (max. 200 Zeichen)

![Anwesenheit erfassen](/img/record-attendance.png)

## Anwesenheit für die ganze Klasse

Nutzen Sie die **Schnellaktionen** für die gesamte Klasse:

- **Alle anwesend** — Setzt alle Schüler auf "Anwesend"
- **Alle abwesend** — Setzt alle Schüler auf "Abwesend"

Danach können Sie einzelne Schüler individuell anpassen.

## Nachträgliche Einträge

Sie können Anwesenheit auch für vergangene Tage eintragen, indem Sie das **Datum** im Kalender ändern.

## Anwesenheit bearbeiten

Klicken Sie auf einen bestehenden Eintrag, um Status oder Notiz zu ändern.

## Anwesenheit löschen

Einzelne Einträge können über den **Löschen-Button** im Bearbeitungsdialog entfernt werden.
