# Anwesenheitsstatistiken

EduGrade berechnet automatisch Anwesenheitsquoten und zeigt diese übersichtlich an.

## Kalenderansicht

In der Anwesenheitsansicht sehen Sie einen **Kalender** mit farbcodierten Tagen:

![Anwesenheitskalender](/img/attendance-calendar.png)

Die Farben zeigen den Gesamtstatus des jeweiligen Tages auf einen Blick.

## Statistiken pro Schüler

Für jeden Schüler wird die **Anwesenheitsquote** berechnet:

```
Anwesenheitsquote = Anwesend / (Anwesend + Verspätet + Abwesend) × 100%
```

## Farbliche Indikatoren

| Farbe | Bedeutung |
|-------|-----------|
| 🟢 Grün | Über Mindestanwesenheit + Warnschwelle — alles in Ordnung |
| 🟡 Gelb | Zwischen Mindestanwesenheit und Warnschwelle — Vorsicht! |
| 🔴 Rot | Unter Mindestanwesenheit — kritisch |

Die Schwellenwerte werden in den [Anwesenheitseinstellungen](anwesenheit-einstellungen.md) festgelegt.

## Statistiken pro Fach

Wechseln Sie zwischen Fächern, um die Anwesenheitsquote pro Fach einzusehen. So erkennen Sie schnell, in welchen Fächern ein Schüler häufig fehlt.
