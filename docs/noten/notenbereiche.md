# Notenbereiche

Notenbereiche definieren, welcher Prozentwert welcher Note entspricht. Sie werden verwendet bei:

- Der Umrechnung von Prozenteingaben in Noten
- Der Berechnung der Endnote aus dem gewichteten Durchschnitt

## Standardbereiche

| Note | Bezeichnung | Prozentbereich |
|------|-------------|---------------|
| 1 | Sehr gut | 85–100% |
| 2 | Gut | 70–84% |
| 3 | Befriedigend | 55–69% |
| 4 | Genügend | 40–54% |
| 5 | Nicht genügend | 0–39% |

## Notenbereiche anpassen

1. Öffnen Sie **Einstellungen** → **Notenbereiche**
2. Passen Sie die **Prozentschwellen** für jede Note an
3. Die Änderungen werden sofort gespeichert

![Notenbereiche konfigurieren](/img/grade-ranges.png)

:::info Hinweis
Die Notenbereiche gelten für alle Klassen und Fächer gleich. Passen Sie sie an Ihr Bewertungssystem an.
:::
