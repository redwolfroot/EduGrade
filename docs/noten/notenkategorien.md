# Notenkategorien

Notenkategorien bestimmen, wie Noten organisiert und gewichtet werden. Typische Kategorien sind Schularbeiten, Mitarbeit, Hausübungen oder Tests.

## Kategorie erstellen

1. Öffnen Sie **Einstellungen** → **Kategorien**
2. Klicken Sie auf **Kategorie hinzufügen**
3. Füllen Sie das Formular aus:
   - **Name** — z.B. "Schularbeit" (max. 100 Zeichen)
   - **Gewichtung** — Prozentwert (z.B. 50 für 50%)
   - **Nur Plus/Minus** — Wenn diese Kategorie nur +/~/- Bewertungen erlaubt
4. Bestätigen Sie mit **Erstellen**

![Kategorie erstellen](/img/create-category.png)

## Beispielkonfiguration

| Kategorie | Gewichtung | Typ |
|-----------|-----------|-----|
| Schularbeit | 50% | Numerisch (1–5) |
| Mitarbeit | 25% | Plus/Minus (+/~/-) |
| Hausübung | 25% | Numerisch (1–5) |

## Kategorie bearbeiten

1. Klicken Sie auf den **Bearbeiten-Button** neben der Kategorie
2. Ändern Sie Name, Gewichtung oder Typ
3. Bestätigen Sie mit **Speichern**

Änderungen gelten für **alle vorhandenen und zukünftigen Noten** dieser Kategorie.

## Kategorie löschen

1. Klicken Sie auf den **Löschen-Button** neben der Kategorie
2. Bestätigen Sie die Sicherheitsabfrage

:::warning Achtung
Bestehende Noten in dieser Kategorie verlieren ihre Kategorie-Zuordnung.
:::

:::tip Tipp
Erstellen Sie Ihre Kategorien am besten, bevor Sie die ersten Noten vergeben. Die [Gewichtung](gewichtung.md) der Kategorien bestimmt den Endnoten-Durchschnitt.
:::
