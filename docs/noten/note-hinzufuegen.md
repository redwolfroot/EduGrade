# Note hinzufügen

## Einzelne Note vergeben

1. Klicken Sie in der Klassenansicht auf die entsprechende Zelle in der Notentabelle oder auf **Note hinzufügen** beim Schüler
2. Füllen Sie das Notenformular aus:
   - **Kategorie** — Wählen Sie eine [Notenkategorie](notenkategorien.md) (z.B. Schularbeit, Mitarbeit)
   - **Notenwert** — Numerisch (1–5) oder Plus/Minus (+/~/-)
   - **Oder Prozent** — Geben Sie einen Prozentwert ein (0–100%), der automatisch in eine Note umgerechnet wird
   - **Datum** — Standardmäßig das heutige Datum
   - **Bezeichnung** — Optional (z.B. "SA 1", "Test Kapitel 3")
   - **Ausstehend** — Markieren Sie die Note als noch nicht eingetragen
   - **In Durchschnitt einbeziehen** — An/Aus
3. Bestätigen Sie mit **Speichern**

![Note hinzufügen](/img/add-grade.png)

## Prozent-Eingabe

Wenn Sie einen Prozentwert eingeben, wird dieser anhand der konfigurierten [Notenbereiche](notenbereiche.md) automatisch in eine Note umgerechnet. Beispiel:

| Prozent | Note |
|---------|------|
| 92% | 1 |
| 75% | 2 |
| 60% | 3 |
| 45% | 4 |
| 30% | 5 |

## Sammelnoten vergeben

Sie können dieselbe Note an **mehrere Schüler gleichzeitig** vergeben:

1. Wählen Sie die gewünschten Schüler über die Checkboxen aus
2. Klicken Sie auf **Note für Auswahl hinzufügen**
3. Kategorie, Datum und Bezeichnung gelten für alle ausgewählten Schüler
4. Der Notenwert kann individuell oder gleich eingetragen werden

## Ausstehende Noten

Markieren Sie eine Note als **ausstehend**, wenn Sie den Wert später nachtragen möchten. Ausstehende Noten:

- Werden visuell gekennzeichnet
- Fließen **nicht** in den Durchschnitt ein
- Erinnern Sie daran, dass noch eine Bewertung fehlt
