# Note bearbeiten & löschen

## Note bearbeiten

1. Klicken Sie auf die **Note** in der Notentabelle oder in der Schüler-Detailansicht
2. Ändern Sie die gewünschten Felder:
   - Notenwert
   - Kategorie
   - Datum
   - Bezeichnung
   - Ausstehend-Status
   - In Durchschnitt einbeziehen
3. Bestätigen Sie mit **Speichern**

![Note bearbeiten](/img/edit-grade.png)

## Note vom Durchschnitt ausschließen

Sie können einzelne Noten vom Durchschnitt **ausschließen**, ohne sie zu löschen. Das ist nützlich für:

- Übungsnoten, die nicht zählen sollen
- Bedingte Bewertungen
- Probearbeiten

Deaktivieren Sie dazu im Bearbeitungsdialog den Schalter **In Durchschnitt einbeziehen**.

## Note löschen

1. Öffnen Sie den Bearbeitungsdialog der Note
2. Klicken Sie auf **Löschen**
3. Bestätigen Sie die Sicherheitsabfrage

:::danger Achtung
Das Löschen einer Note kann nicht rückgängig gemacht werden.
:::
