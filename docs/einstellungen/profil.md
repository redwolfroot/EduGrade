# Profileinstellungen

Hier verwalten Sie Ihre persönlichen Einstellungen und Schulinformationen.

## Einstellungen öffnen

Klicken Sie auf **Einstellungen** in der Seitenleiste und wählen Sie **Profil**.

## Verfügbare Einstellungen

### Persönliche Daten

- **Anzeigename** — Wird als Begrüßung auf der Startseite angezeigt
- **Schulname** — Optional, für Ihre Zuordnung

### Schultyp

| Schultyp | Notensystem |
|----------|-------------|
| Volksschule | Verbale Beurteilung |
| Sekundarstufe | Numerische Noten (1–5) |

### Standardfächer

Legen Sie Fächer fest, die automatisch für neue Klassen erstellt werden. Mehr dazu unter [Standardfächer](../faecher/standardfaecher.md).
