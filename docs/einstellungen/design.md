# Design

EduGrade bietet einen hellen und einen dunklen Modus sowie wählbare Akzentfarben.

## Modus wechseln

Sie können den Modus an zwei Stellen umschalten:

1. **Seitenleiste** — Klicken Sie auf das Sonnen-/Mond-Symbol
2. **Einstellungen** → **Profil** — Wählen Sie Ihren bevorzugten Modus

![Design-Umschalter](/img/theme-toggle.png)

## Wann welchen Modus verwenden?

| Modus | Empfohlen für |
|-------|---------------|
| Hell | Tageslicht, helle Klassenzimmer |
| Dunkel | Abends, reduzierte Helligkeit, Beamer-Präsentationen |

Ihre Auswahl wird gespeichert und beim nächsten Login beibehalten.

## Akzentfarbe

Neben Hell/Dunkel können Sie die **Akzentfarbe** wählen. Sie wirkt auf Buttons, Links und aktive Elemente.

Öffnen Sie dazu **Einstellungen** → **Profil** und wählen Sie unter **Akzentfarbe** eine der Vorlagen: Coral (Standard), Rot, Orange, Gelb, Grün, Blau, Lila oder Mono (Graustufen).

Die gewählte Farbe wird sofort übernommen und für den nächsten Login gespeichert. Sie funktioniert in beiden Modi (Hell und Dunkel).

:::tip Tipp
**Mono** (Graustufen) eignet sich für eine besonders ruhige, ablenkungsarme Darstellung — z.B. bei Beamer-Präsentationen.
:::
