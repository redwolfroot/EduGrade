# Sprache ändern

EduGrade ist in **Deutsch** und **Englisch** verfügbar.

## Sprache wechseln

1. Öffnen Sie **Einstellungen** → **Profil**
2. Wählen Sie unter **Sprache** die gewünschte Option:
   - 🇩🇪 Deutsch
   - 🇬🇧 English
3. Die Änderung wird **sofort** übernommen — kein Neuladen erforderlich

Alle Menüs, Dialoge, Meldungen und Beschriftungen werden in der gewählten Sprache angezeigt.
